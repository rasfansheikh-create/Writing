# IELTS Writing Task 2 Practice Dashboard

A self-contained IELTS Writing Task 2 practice website with multiple topic categories and practice tests.

## Run locally

Open `index.html` in any modern web browser.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this project folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide your public website URL after deployment.

## Project structure

- `index.html` — main application
- `README.md` — project and deployment instructions
- `.gitignore` — common local/system files excluded from Git

## Notes

The app is fully contained in `index.html`; no build step is required.
